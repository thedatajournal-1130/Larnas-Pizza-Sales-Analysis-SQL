# Larnas-Pizza-Sales-Analysis-SQL
# 📌 Overview
This project analyzes a pizza restaurant's sales data using SQL to uncover key business insights such as revenue trends, top-performing products, and customer ordering behavior.

# 📂 Dataset
The dataset consists of 4 tables:

● orders- order_id, date & time

● order_details- order_details_id,order_id,pizza_id & quantity

● pizzas- pizza_id, pizza_type_id, size & price

● pizza_types- pizza_type_id, name, category & ingredients

# 🛠️ Tools Used

● MySQL – Performed data extraction, transformation, and analysis using joins, aggregations, and window functions to generate business insights

# 🔍 Key Analysis Performed
▶ 🧩 Basic Analysis
  ● Total orders placed 
   
  ● Total revenue generated
   
  ● Highest priced pizza
   
  ● Most common pizza size

▶ ⚙️ Intermediate Analysis

  ● Category-wise sales performance 

  ● Hourly order trends
   
  ● Daily average orders

▶ 🚀 Advanced Analysis

  ● Revenue contribution by pizza type
   
  ● Cumulative revenue over time
   
  ● Top 3 pizzas by revenue per category

# 📊 Key Insights

● 📈 Total Revenue: $817,860+

● 🍕 Most Popular Size: Large (L)

● 🥇 Top Revenue Pizza: Thai Chicken Pizza (~5.3%)

● ⏰ Peak Hours: 12–1 PM and 5–7 PM

● 🏆 Best Performing Category: Classic
